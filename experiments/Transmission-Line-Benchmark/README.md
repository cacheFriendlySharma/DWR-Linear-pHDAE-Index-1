This folder contains the Julia files and Python scripts to generate the .mat files and plots, respectively. Both the Julia files generate a .mat file of the same name, "rcl_ladder_system.mat". Specifically, get_rcl.jl generates the regularized transmission line benchmark used in all the .py files except for transmission_line_waveform_final_draft.py, which uses the .mat file generated by get_rcl_ideal.jl to generate the plots in the paper.
